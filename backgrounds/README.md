# DE duvar kâğıtları

Her masaüstü için kendi klasöründeki wallpaper.png dosyasını kullanın.
PNG, JPEG ve WebP desteklenir. Görsel eksikse mevcut Zelix Aurora duvar kâğıdı kullanılır.
Klasörler: gnome, xfce, hyprland, sway, i3, bspwm.
KDE mevcut otomatik Aurora duvar kâğıdını korur; KDE için ayrı görsel eklemeyin.
Bu görseller seçim ekranındaki ekran görüntülerinden (previews/) ayrıdır.
